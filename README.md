# Does the grid position decide the race outcome?

**Question:** How strongly does starting position determine finishing position in Formula 1, and has this changed between the hybrid era (2014–2021) and the ground-effect era (2022–now)?

## Data
Kaggle – Formula 1 World Championship dataset (Rohan Rao): `results.csv`, `races.csv` in `/data`.

## Analyses (planned)
1. Linear regression: finishing position ~ grid position (finishers only)
2. Logistic regression: P(podium) ~ grid position (all starters)
